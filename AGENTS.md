# Правила проекта Zapret Control

Эти правила действуют для всех задач в этом репозитории.

## Язык и текст

- Все ответы пользователю, README, руководство и тексты интерфейса: по-русски.
- Никогда не использовать длинное тире (U+2014). Только дефис, запятую или двоеточие.

## Ярлык на рабочем столе

- После любой сборки, которая обновляет `release\`, ярлык на рабочем столе должен вести на свежий `release\ZapretControl-<версия>-Portable.exe`.
- Имя ярлыка всегда `Zapret Control`, без версии.
- Ярлык не должен вести на `dist\`, Setup.exe или установленную копию в `%LOCALAPPDATA%`.
- Реализация: `tools\update-shortcut.ps1`. Его обязаны вызывать `make-portable.ps1`, `make-release.ps1` и `make-setup.ps1` (если не передан `-NoDesktopShortcut`).
- Проверка: цель ярлыка и версия exe должны совпадать с последним релизом.
- Установщик (`install.ps1`) не должен удалять или перезаписывать чужой ярлык: он трогает только ярлыки, ведущие в `%LOCALAPPDATA%\ZapretControl`. Если ярлык уже ведёт на `release\`, установка его сохраняет.

## Сборка и релиз

- Версия задаётся в `src\Zapret.App\Zapret.App.csproj` и дублируется в `src\Zapret.Core\UpdateService.cs` (`AppInfo.Version`) и `src\Zapret.Setup\Zapret.Setup.csproj`.
- Портативный exe именуется с версией и словом Portable: `release\ZapretControl-<версия>-Portable.exe`, в заголовке окна и свойствах файла тоже `Zapret Control Portable`. Это тот же самый бинарник: слово Portable в имени файла включает его в заголовке. Вариант `-fx` (без встроенного рантайма) больше не собирается.
- Обычная сборка для установщика: `dist\ZapretControl-<версия>.exe`, без слова Portable в заголовке.
- Установщик: `release\ZapretControl-<версия>-Setup.exe`; архив: `release\ZapretControl-<версия>.zip`.
- В `release\` хранится только текущая версия. Предыдущие автоматически переносятся в `release\backup\<версия>\`; там хранятся две последние версии до текущей, более старые удаляются.
- Очистка: `tools\cleanup-release.ps1`, вызывается из `make-portable.ps1`, `make-release.ps1` и `make-setup.ps1`.
- Перед релизом прогнать проверки: `dotnet run --project src\Zapret.Check -c Release -- src\zapret`.
- Команды сборки: `tools\make-portable.ps1`, затем `tools\make-release.ps1`, затем `tools\make-setup.ps1`.

## Списки

- Файлы `lists\*-user.txt` принадлежат пользователю, приложение их не перезаписывает.
- Базовые списки при обновлении объединяются, ручные правки сохраняются.
- Перед массовыми изменениями списков делать резервную копию папки `lists`.
- «Не обходить YouTube» по умолчанию выключено: YouTube под обходом, пока пользователь сам не нажмёт кнопку.
